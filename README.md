# Лабораторная работа №1 - Supervised Learning

Лабораторная работа посвящена задаче **бинарной классификации**: прогнозированию победы Ferrari в гонке Formula 1 на основе информации о трассе, стартовых позициях и результатов предыдущих гонок.

## Что находится в репозитории

- `lab1_supervised.ipynb` - основной Jupyter Notebook с анализом данных, обучением моделей и сравнением результатов;
- `build_ferrari_dataset.py` - скрипт для самостоятельного сбора и формирования датасета;
- `ferrari_f1_dataset.csv` - итоговый датасет;
- `my_model.py` - собственная реализация Decision Tree и Random Forest.

## Что выполнено в работе

В лабораторной работе:

- самостоятельно собран датасет по гонкам Formula 1;
- проведён исследовательский анализ данных;
- обработаны пропуски и категориальные признаки;
- созданы признаки на основе результатов предыдущих гонок;
- выполнено разделение данных на train / validation / test со стратификацией;
- реализован baseline;
- обучен `RandomForestClassifier` из `sklearn`;
- выполнен подбор гиперпараметров с помощью кросс-валидации;
- рассчитаны Accuracy, Precision, Recall и F1-score;
- самостоятельно реализованы Decision Tree и Random Forest;
- проведено сравнение собственной модели с реализацией из `sklearn`.

При создании исторических признаков используется только информация из **предыдущих гонок**, чтобы избежать data leakage.
